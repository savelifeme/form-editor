# canvas-editor 项目架构概览

## 一、项目概述

| 属性 | 说明 |
|------|------|
| **名称** | `@hufe921/canvas-editor` |
| **类型** | Canvas/SVG 富文本编辑器库 |
| **版本** | v0.9.120 |
| **构建工具** | Vite + TypeScript |
| **应用场景** | EMR 电子病历、WYSIWYG 编辑器 |

## 六、关键枚举说明

| 枚举 | 用途 |
|------|------|
| `ElementType` | TEXT, IMAGE, TABLE, HYPERLINK, CHECKBOX, CONTROL, DATE... |
| `EditorMode` | EDIT, READONLY, CLEAN, FORM, PRINT, DESIGN |
| `ControlType` | TEXT, SELECT, DATE, NUMBER, CHECKBOX... |
| `PageMode` | PAGING（分页）/ CONTINUITY（连续）|
| `RowFlex` | 左对齐、居中、右对齐、两端对齐 |
| `TableBorder` | 表格边框样式 |

## 七、数据模型

```typescript
// 核心元素结构
interface IElement {
  type: ElementType      // 元素类型
  value: string          // 文本内容或其他值
  style?: IElementStyle  // 样式
  rowFlex?: RowFlex      // 行对齐
  level?: TitleLevel     // 标题级别
  src?: string           // 图片地址
  ...
}

// 编辑器数据
interface IEditorData {
  header?: IElement[]    // 页眉数据
  main: IElement[]       // 正文数据
  footer?: IElement[]    // 页脚数据
}
```

## 九、后续改造建议关注点

1. **新增元素类型** → 在 `draw/particle/` 添加新的 Particle 类
2. **新增页面元素** → 在 `draw/frame/` 添加 Frame 组件
3. **新增交互功能** → 在 `draw/interactive/` 或 `core/command/` 扩展
4. **新增快捷键** → 在 `core/shortcut/` 注册
5. **新增控件** → 参考 Control 相关实现，扩展 `ControlType`
